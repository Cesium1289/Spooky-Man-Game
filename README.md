# Spooky-Man-Game

## What is this project?
Spooky Man is a game inspired by the original Slender Man, built using the Unity game engine. The goal is to collect 8 pages that are scattered around the map while evading the Spooky Man. You can throw object at him to stop his pursuit. You must collect all 8 pages to win the game.  Check out this video demo of an earlier build: https://youtu.be/qTZw--nKSII.
